## Datos de flechas

```typescript
export type Arrow = {
    id: string;
    label: string;
    from: Uid;
    to: Uid;
    delta1: {
        x: number;
        y: number;
    };
    delta2: {
        x: number;
        y: number;
    };
    bidirectional?: boolean;
};
```

Los datos de una flecha contienen los siguientes campos:

- `id`: Identificador único
- `label`: Texto mostrado
- `from`: Id del nodo de origen
- `to`: Id del nodo de destino
- `delta1`: Desplazamiento del punto de control del nodo de origen
- `delta2`: Desplazamiento del punto de control del nodo de destino
- `bidirectional`: Indica si la flecha es bidireccional

Los puntos de control son los de la curva de Bézier cuadrática de la flecha. Ajustando sus desplazamientos puedes modificar la forma de la flecha. Consulta el [comando `C` de rutas SVG](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Paths#b%C3%A9zier_curves) para más información.
