## Datos del resumen

```typescript
export interface Summary {
    id: string;
    text: string; 
    parent: string; 
    start: number; 
    end: number;
}
```

Los datos del resumen contienen los siguientes campos:

- `id`: Identificador único
- `text`: Texto del resumen
- `parent`: Id del nodo padre al que pertenece el resumen
- `start`: Índice del primer nodo hijo incluido en el resumen
- `end`: Índice del último nodo hijo incluido en el resumen

:::warning

El nodo padre de un resumen no puede ser el nodo raíz.

:::
