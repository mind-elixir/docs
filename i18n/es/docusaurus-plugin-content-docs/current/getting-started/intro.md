# ¿Qué es Mind Elixir Core?

![](/img/screenshot.png)

**Mind Elixir Core** es un framework JavaScript de código abierto para mapas mentales, diseñado para aprovechar las ventajas de esta forma de representación. Incluye las siguientes características:

- Sin dependencias, instalación rápida (33 kB tras gzip)
- Operaciones con nodos de alto rendimiento
- No está ligado a ningún framework de frontend
- Compatibilidad con plugins
- Salida en formato SVG o PNG
- Selección múltiple de nodos y arrastrar y soltar
- Resúmenes de varios nodos
- Enlaces entre nodos
- Atajos de teclado prácticos
- Funciones de deshacer y rehacer
- Temas personalizables para dar más vida a tus nodos
- Posibilidad de modificar ciertos estilos CSS

:::info

El mapa mental es una herramienta de pensamiento revolucionaria que ayuda a procesar información, generar nuevas ideas, mejorar la memoria, aprovechar el tiempo libre y perfeccionar los métodos de trabajo. Su principio básico imita la estructura de las neuronas del cerebro: desde el centro se ramifica hasta formar un diagrama complejo que sintoniza con el modo en que trabaja el cerebro. Este diagrama captura la información mediante patrones de ramificación y asociación y la presenta de forma creativa y eficiente.

:::
