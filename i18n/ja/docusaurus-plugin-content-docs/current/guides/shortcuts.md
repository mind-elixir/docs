# ショートカットキー

ノードを右クリックして操作するのは不便で、作業や学習の効率が大幅に低下します。Mind Elixir Core はより効率的なショートカットキーをサポートし、スムーズなマインドマップの作成とナビゲーションを可能にします！これらのショートカットにより、複雑なマインドマップの閲覧と探索がより便利で直感的になります。

| ショートカットキー | 機能                   |
| ------------------ | ---------------------- |
| Enter              | 兄弟ノードを挿入       |
| Shift + Enter      | 前方に兄弟ノードを挿入 |
| Tab                | 子ノードを挿入         |
| Ctrl + Enter       | 親ノードを挿入         |
| F1                 | マインドマップを中央に |
| F2                 | 現在のノードを編集     |
| ↑                  | 前のノードを選択       |
| ↓                  | 次のノードを選択       |
| ← / →              | 左右のノードを選択     |
| PageUp / Alt + ↑   | 上に移動               |
| PageDown / Alt + ↓ | 下に移動               |
| Ctrl + ↑           | 両側に分散配置         |
| Ctrl + ←           | 左側に分散配置         |
| Ctrl + →           | 右側に分散配置         |
| Ctrl + C           | コピー                 |
| Ctrl + X           | カット                 |
| Ctrl + V           | ペースト               |
| Delete / Backspace | ノード/矢印/要約を削除 |
| Ctrl + "+"         | マインドマップを拡大   |
| Ctrl + "-"         | マインドマップを縮小   |
| Ctrl + 0           | ズームをリセット       |
| Ctrl + K, Ctrl + 0 | 全ノードを折りたたみ   |
| Ctrl + K, Ctrl + = | 全ノードを展開         |
| Ctrl + K, Ctrl + 1-9 | レベルNまで展開      |

`↑` / `↓` はブランチの境界を越えます。最後の子ノードで `ArrowDown`、最初の子ノードで `ArrowUp` を押すと最も近い隣接ブランチへ移動し、その先頭／末尾の子ノード（折りたたまれている場合はブランチノード自体）に着地します。

折りたたみ／展開はアンドゥ可能で、`Ctrl + Z` で直前の折りたたみ状態に戻せます。アウトライナーとマップの折りたたみは同じアンドゥ履歴を共有します。暗黙の展開や `expandNode(node, { silent: true })` による静かな展開は履歴に残りません。また `refresh(data)` はフォーカスモードを解除し、データ反映後に `refresh` イベントを一度発火します。
