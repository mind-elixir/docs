# Mind Elixir Core とは？

![](/img/screenshot.png)

**Mind Elixir Core** は、マインドマップの利点を活かすために設計されたオープンソースの JavaScript マインドマップフレームワークです。次のような機能を備えています：

- 依存ゼロ、高速インストール（gzip 後 33 kB）
- 高パフォーマンスなノード操作
- 特定のフロントエンドフレームワークに依存しない
- プラグインに対応
- SVG または PNG 形式で書き出し
- 複数ノードの選択とドラッグ＆ドロップ
- 複数ノードの要約
- ノード同士のリンク
- 実用的なキーボードショートカット
- 元に戻す／やり直し
- ノードを彩るカスタムテーマ
- 一部の CSS スタイル変更に対応

:::info

マインドマップ（Mind Map）は、情報を整理し、新しいアイデアを生み、記憶を強化し、余暇を有効に使い、作業方法を改善する革新的な思考ツールです。その基本原理は脳のニューロン構造を模倣することにあります。中心から枝を伸ばして脳の働き方に呼応する複雑な図を形成し、分岐と連想のパターンで情報を捉え、創造的かつ効率的な形で提示します。

:::
