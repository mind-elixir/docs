# Playground

Experimente o Mind Elixir Core ao vivo em plataformas como [Codepen](https://codepen.io/pen?template=GReMQPX), CodeSandbox, [stackblitz](https://stackblitz.com/) e outras.

Aqui estão os playgrounds para usar o Mind Elixir Core com JavaScript puro e com frameworks frontend como React:

- Vanilla JS - https://codepen.io/ssshooter/pen/QWomvEp
- React - https://codesandbox.io/p/sandbox/mind-elixir-4-x-react-18-x-4pkp83
- Vue3 - https://stackblitz.com/edit/vitejs-vite-b5xpmz

:::tip

Se você encontrar problemas ou bugs, também pode reproduzi-los no playground para agilizar a resolução.

:::
