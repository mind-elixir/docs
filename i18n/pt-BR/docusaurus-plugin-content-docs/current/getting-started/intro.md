# O que é o Mind Elixir Core?

![](/img/screenshot.png)

**Mind Elixir Core** é um framework JavaScript open source para mapas mentais, criado para aproveitar as vantagens dessa forma de representação. Ele oferece os seguintes recursos:

- Zero dependências, instalação rápida (33 kB após gzip)
- Operações com nós de alto desempenho
- Não depende de nenhum framework frontend
- Suporte a plugins
- Saída em SVG ou PNG
- Seleção múltipla de nós e arrastar e soltar
- Resumo de vários nós
- Ligação entre nós
- Suporte a atalhos de teclado práticos
- Funções de desfazer e refazer
- Temas personalizáveis para dar mais vida aos seus nós
- Suporte a algumas alterações de estilo CSS

:::info

O mapa mental é uma ferramenta de pensamento revolucionária que ajuda a processar informações, gerar novas ideias, melhorar a memória, aproveitar melhor o tempo livre e aprimorar métodos de trabalho. Seu princípio central imita a estrutura dos neurônios no cérebro: a partir do centro, ramifica-se até formar um diagrama complexo que acompanha o modo como o cérebro trabalha. Esse diagrama captura informações por meio de padrões de ramificação e associação e as apresenta de forma criativa e eficiente.

:::
