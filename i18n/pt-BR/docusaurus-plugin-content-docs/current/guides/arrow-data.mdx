## Dados das setas

```typescript
export type Arrow = {
    id: string;
    label: string;
    from: Uid;
    to: Uid;
    delta1: {
        x: number;
        y: number;
    };
    delta2: {
        x: number;
        y: number;
    };
    bidirectional?: boolean;
};
```

Os dados de uma seta contêm os seguintes campos:

- `id`: Identificador único
- `label`: Texto exibido
- `from`: Id do nó de origem
- `to`: Id do nó de destino
- `delta1`: Deslocamento do ponto de controle do nó de origem
- `delta2`: Deslocamento do ponto de controle do nó de destino
- `bidirectional`: Indica se a seta é bidirecional

Os pontos de controle são os da curva de Bézier quadrática da seta. Ajustando seus deslocamentos, você modifica o formato da seta. Consulte o [comando `C` de caminhos SVG](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Paths#b%C3%A9zier_curves) para mais informações.
