## Dados do resumo

```typescript
export interface Summary {
    id: string;
    text: string; 
    parent: string; 
    start: number; 
    end: number;
}
```

Os dados do resumo contêm os seguintes campos:

- `id`: Identificador único
- `text`: Texto do resumo
- `parent`: Id do nó pai ao qual o resumo pertence
- `start`: Índice do primeiro nó filho do resumo
- `end`: Índice do último nó filho do resumo

:::warning

O nó pai de um resumo não pode ser o nó raiz.

:::
