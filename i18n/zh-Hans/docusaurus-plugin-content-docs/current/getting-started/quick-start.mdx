# 安装与使用

## 安装

```
npm i mind-elixir -S
```

## 使用

```js
import MindElixir from 'mind-elixir'

let options = {
  el: '#map', // or HTMLDivElement
}

let mind = new MindElixir(options)

// create new map data
const data = MindElixir.new('new topic')
mind.init(data)
```

要使用 Mind Elixir Core，在 `options` 中只要传入一个 `el`（代表挂载的目标 DOM 元素）即可。更多配置可以查阅[完整配置](../api/mind-elixir.options.md)。

:::warning

因为 Mind Elixir Core 挂载时高度为容器高度的 100%，所以请务必设置容器高度，否则造成显示异常。

:::

```html
<div id="map"></div>
<style>
  #map {
    height: 500px;
    width: 100%;
  }
</style>
```

## 对思维导图的操作

- 操作与常见思维导图应用基本一致
- 快捷键可见[快捷键章节](../guides/shortcuts.md)
- 鼠标左键可拖动节点，或多选节点
- 鼠标右键可拖动画布
- 右键选择“连接”后再点击另一个节点，可连接两个节点

## 数据导出与更新

用户对思维导图的操作后，数据随即改变，可以调用 `getData` 方法获取最新数据。数据格式可见[数据导出](../guides/data-export.md)。

```js
const data = mind.getData()
```

有需要使用整组新数据刷新当前思维导图时，可以使用 `refresh` 方法。

```js
mind.refresh(data)
```

## 从右向左的语言

处理阿拉伯语、希伯来语、波斯语或乌尔都语内容时，可以传入 `rtl: true` 并使用内置的阿拉伯语语言包：

```js
import MindElixir from 'mind-elixir'
import { ar } from 'mind-elixir/i18n'

const mind = new MindElixir({
  el: '#map',
  rtl: true,
  contextMenu: { locale: ar },
})
```

`rtl` 只改变节点文字、编辑器、标签和右键菜单的文字方向，不影响分支布局轴（`direction`）。更多选项见 [v6 API 指南](./migration-v6.md)。
