# 요약

Mind Elixir Core는 아래와 같이 마인드맵에 노드 요약을 추가할 수 있습니다:

    }}
 />

## 요약 데이터

```typescript
export interface Summary {
    id: string;
    text: string; 
    parent: string; 
    start: number; 
    end: number;
}
```

요약 데이터에는 다음 필드가 있습니다:

- `id`: 고유 식별자
- `text`: 요약 텍스트
- `parent`: 요약이 속한 부모 노드 ID
- `start`: 요약에 포함되는 첫 자식 노드 인덱스
- `end`: 요약에 포함되는 마지막 자식 노드 인덱스

:::warning

요약의 부모 노드는 루트 노드가 될 수 없습니다.

:::
