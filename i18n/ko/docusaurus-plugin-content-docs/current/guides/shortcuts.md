# 단축키

오른쪽 클릭 메뉴로 노드를 조작하면 번거롭고 작업·학습 효율이 크게 떨어집니다. Mind Elixir Core는 더 효율적인 단축키를 지원해 다이어그램을 매끄럽게 만들고 마인드맵을 자유롭게 탐색할 수 있게 합니다. 이 단축키 덕분에 복잡한 마인드맵을 훨씬 편하고 직관적으로 살펴볼 수 있습니다.

| 단축키 | 기능 |
| ------------------ | ------------------------- |
| Enter | 형제 노드 삽입 |
| Shift + Enter | 앞에 형제 노드 삽입 |
| Tab | 자식 노드 삽입 |
| Ctrl + Enter | 부모 노드 삽입 |
| F1 | 마인드맵 가운데 정렬 |
| F2 | 현재 노드 편집 |
| ↑ | 이전 노드 선택 |
| ↓ | 다음 노드 선택 |
| ← / → | 왼쪽/오른쪽 노드 선택 |
| PageUp / Alt + ↑ | 위로 이동 |
| PageDown / Alt + ↓ | 아래로 이동 |
| Ctrl + ↑ | 양쪽 레이아웃 사용 |
| Ctrl + ← | 왼쪽 레이아웃 사용 |
| Ctrl + → | 오른쪽 레이아웃 사용 |
| Ctrl + C | 복사 |
| Ctrl + X | 잘라내기 |
| Ctrl + V | 붙여넣기 |
| Delete / Backspace | 노드/화살표/요약 삭제 |
| Ctrl + "+" | 마인드맵 확대 |
| Ctrl + "-" | 마인드맵 축소 |
| Ctrl + 0 | 확대/축소 초기화 |
| Ctrl + K, Ctrl + 0 | 모든 노드 접기 |
| Ctrl + K, Ctrl + = | 모든 노드 펼치기 |
| Ctrl + K, Ctrl + 1-9 | N단계까지 펼치기 |

`↑` / `↓`는 가지 경계를 넘습니다. 마지막 자식에서 `ArrowDown`, 첫 자식에서 `ArrowUp`을 누르면 가장 가까운 형제 가지로 이동해 그 첫/마지막 자식에 도착하며, 접혀 있다면 가지 노드 자체에 도착합니다.

접기/펼치기는 실행 취소가 가능하므로 `Ctrl + Z`로 이전 접기 상태를 복원합니다. 아웃라이너와 마인드맵에서 접은 내용은 하나의 실행 취소 타임라인을 공유합니다. 조용한 펼치기(`expandNode(node, { silent: true })`)는 기록을 남기지 않습니다. `refresh(data)`는 포커스 모드를 해제하고 데이터가 적용되면 `refresh` 이벤트를 발생시킵니다.
