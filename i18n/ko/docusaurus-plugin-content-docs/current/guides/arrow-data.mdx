## 화살표 데이터

```typescript
export type Arrow = {
    id: string;
    label: string;
    from: Uid;
    to: Uid;
    delta1: {
        x: number;
        y: number;
    };
    delta2: {
        x: number;
        y: number;
    };
    bidirectional?: boolean;
};
```

화살표 데이터에는 다음 필드가 있습니다:

- `id`: 고유 식별자
- `label`: 표시 텍스트
- `from`: 시작 노드 id
- `to`: 대상 노드 id
- `delta1`: 시작 노드의 제어점 오프셋
- `delta2`: 대상 노드의 제어점 오프셋
- `bidirectional`: 양방향 화살표 여부

제어점은 화살표의 2차 베지어 곡선 제어점을 말합니다. 오프셋을 조정하면 화살표 모양을 바꿀 수 있습니다. 자세한 내용은 [SVG Path `C` 명령](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Paths#b%C3%A9zier_curves)을 참고하세요.
