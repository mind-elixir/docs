# Mind Elixir Core란?

![](/img/screenshot.png)

**Mind Elixir Core**는 마인드맵의 장점을 활용하도록 설계된 오픈 소스 JavaScript 마인드맵 프레임워크입니다. 다음과 같은 기능을 제공합니다:

- 의존성 없음, 빠른 설치(gzip 후 33 kB)
- 고성능 노드 연산
- 특정 프런트엔드 프레임워크에 종속되지 않음
- 플러그인 지원
- SVG 또는 PNG 형식으로 출력
- 다중 노드 선택 및 드래그 앤 드롭
- 여러 노드 요약
- 노드 연결
- 실용적인 단축키 지원
- 실행 취소 및 다시 실행
- 노드에 생동감을 더하는 사용자 정의 테마
- 일부 CSS 스타일 수정 지원

:::info

마인드맵은 정보를 처리하고, 새로운 아이디어를 만들고, 기억력을 높이고, 여가 시간을 활용하고, 업무 방식을 개선하는 데 도움을 주는 혁신적인 사고 도구입니다. 핵심 원리는 뇌의 뉴런 구조를 모방하는 것입니다. 중심에서부터 가지를 뻗어 뇌의 작동 방식에 맞는 복잡한 다이어그램을 형성합니다. 이 다이어그램은 분기와 연관 패턴으로 정보를 담아내고, 창의적이며 효율적인 방식으로 정보를 보여줍니다.

:::
