# Playground

Probiere Mind Elixir Core live auf Plattformen wie [Codepen](https://codepen.io/pen?template=GReMQPX), CodeSandbox, [stackblitz](https://stackblitz.com/) und weiteren aus.

Hier sind Playgrounds für die Verwendung von Mind Elixir Core mit reinem JavaScript und in Frontend-Frameworks wie React:

- Vanilla JS - https://codepen.io/ssshooter/pen/QWomvEp
- React - https://codesandbox.io/p/sandbox/mind-elixir-4-x-react-18-x-4pkp83
- Vue3 - https://stackblitz.com/edit/vitejs-vite-b5xpmz

:::tip

Wenn du auf Fehler oder Bugs stößt, kannst du sie im Playground reproduzieren, damit sie schneller behoben werden.

:::
