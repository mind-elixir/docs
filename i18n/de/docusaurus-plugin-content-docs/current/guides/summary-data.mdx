## Zusammenfassungsdaten

```typescript
export interface Summary {
    id: string;
    text: string; 
    parent: string; 
    start: number; 
    end: number;
}
```

Die Zusammenfassungsdaten enthalten folgende Felder:

- `id`: Eindeutige Kennung
- `text`: Text der Zusammenfassung
- `parent`: ID des übergeordneten Knotens, zu dem die Zusammenfassung gehört
- `start`: Index des ersten untergeordneten Knotens der Zusammenfassung
- `end`: Index des letzten untergeordneten Knotens der Zusammenfassung

:::warning

Der übergeordnete Knoten einer Zusammenfassung darf nicht der Wurzelknoten sein.

:::
