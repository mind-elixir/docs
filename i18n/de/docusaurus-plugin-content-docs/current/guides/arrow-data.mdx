## Pfeildaten

```typescript
export type Arrow = {
    id: string;
    label: string;
    from: Uid;
    to: Uid;
    delta1: {
        x: number;
        y: number;
    };
    delta2: {
        x: number;
        y: number;
    };
    bidirectional?: boolean;
};
```

Pfeildaten enthalten folgende Felder:

- `id`: Eindeutige Kennung
- `label`: Angezeigter Text
- `from`: ID des Quellknotens
- `to`: ID des Zielknotens
- `delta1`: Versatz des Kontrollpunkts für den Quellknoten
- `delta2`: Versatz des Kontrollpunkts für den Zielknoten
- `bidirectional`: Gibt an, ob der Pfeil bidirektional ist

Kontrollpunkte sind die Kontrollpunkte der quadratischen Bézier-Kurve des Pfeils. Über ihre Versätze kannst du die Form des Pfeils verändern. Weitere Informationen findest du beim [SVG-Pfad-Befehl `C`](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Paths#b%C3%A9zier_curves).
