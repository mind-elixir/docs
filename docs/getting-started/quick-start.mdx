# Installation and Usage

## Installation

```bash
npm i mind-elixir -S
```

## Usage

```js
import MindElixir from 'mind-elixir'

let options = {
  el: '#map', // or HTMLDivElement
}

let mind = new MindElixir(options)

// create new map data
const data = MindElixir.new('new topic')
mind.init(data)
```

To use Mind Elixir Core, simply pass an `el` (representing the target DOM element to be mounted) in the `options`. For more configurations, you can refer to the [complete options](../api/mind-elixir.options).

:::warning

Since Mind Elixir Core mounts with a height of 100% of the container, be sure to set the container height to avoid display abnormalities.

:::

```html
<div id="map"></div>
<style>
  #map {
    height: 500px;
    width: 100%;
  }
</style>
```

## Interactions with Mind Maps

- Interactions are similar to common mind mapping applications
- Shortcut keys can be found in the [Shortcuts section](../guides/shortcuts.md)
- Left mouse button can drag nodes or select multiple nodes
- Right mouse button can drag the canvas
- After selecting "Connect" with the right mouse button, click on another node to connect the two nodes

## Data Export and Update

After user interactions with the mind map, the data changes accordingly. You can use the `getData` method to retrieve the latest data. The data format can be found in [Data Export](../guides/data-export.md).

```js
const data = mind.getData()
```

If you need to refresh the current mind map with an entirely new set of data, you can use the `refresh` method.

```js
mind.refresh(data)
```

## Right-to-left languages

For Arabic, Hebrew, Persian or Urdu content, pass `rtl: true` and use the bundled Arabic locale:

```js
import MindElixir from 'mind-elixir'
import { ar } from 'mind-elixir/i18n'

const mind = new MindElixir({
  el: '#map',
  rtl: true,
  contextMenu: { locale: ar },
})
```

`rtl` only changes the text direction of node topics, the editor, labels and the context menu — the branch layout axis (`direction`) is unaffected. See the [v6 API Guide](./migration-v6.md) for more options.
